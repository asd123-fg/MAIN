📊 DATABASE SCHEMA
═════════════════════════════════════════════════════════════════════════════

USERS TABLE
├── id (UUID)              ← Primary Key
├── name (VARCHAR)         
├── email (VARCHAR)        ← UNIQUE, indexed
├── password (VARCHAR)     ← bcryptjs hashed
├── role (ENUM)            ← admin | merchant | customer
└── created_at/updated_at  ← Auto-managed timestamps

PRODUCTS TABLE
├── id (UUID)              ← Primary Key
├── merchant_id (UUID)     ← Foreign Key → users.id
├── name (VARCHAR)
├── description (TEXT)
├── price (DECIMAL)
├── image (TEXT)
└── created_at/updated_at

CART TABLE
├── id (UUID)              ← Primary Key
├── user_id (UUID)         ← Foreign Key → users.id, UNIQUE per product
├── product_id (UUID)      ← Foreign Key → products.id
├── quantity (INTEGER)     ← Must be > 0
└── created_at/updated_at

ORDERS TABLE
├── id (UUID)              ← Primary Key
├── user_id (UUID)         ← Foreign Key → users.id
├── product_id (UUID)      ← Foreign Key → products.id
├── quantity (INTEGER)
├── status (VARCHAR)       ← pending | processing | shipped | delivered | cancelled
└── created_at/updated_at

All tables include:
- UUID primary keys
- Foreign key constraints with CASCADE delete
- Automatic updated_at timestamps
- Optimized indexes for queries
- Row Level Security policies

🚀 GETTING STARTED
═════════════════════════════════════════════════════════════════════════════

1. INSTALL DEPENDENCIES
   npm install

2. SET UP ENVIRONMENT
   cp .env.example .env
   [Edit .env with your Supabase credentials]

3. CREATE DATABASE SCHEMA
   → Go to Supabase SQL Editor
   → Copy database/schema.sql content
   → Execute

4. START SERVER
   npm run dev          # Development with auto-reload
   npm start            # Production mode

5. TEST THE API
   → GET http://localhost:3000/api/health
   → Import POSTMAN_COLLECTION.json into Postman
   → Follow QUICKSTART.md for testing

🌐 FRONTEND INTEGRATION
═════════════════════════════════════════════════════════════════════════════

LOCAL DEVELOPMENT
  const API_BASE_URL = 'http://localhost:3000/api';

AFTER DEPLOYMENT TO RENDER
  const API_BASE_URL = 'https://your-backend-name.onrender.com/api';

EXAMPLE FETCH CALL
  const token = localStorage.getItem('token');
  fetch(`${API_BASE_URL}/products`, {
    method: 'GET',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${token}`
    }
  })
  .then(res => res.json())
  .then(data => {
    if (data.success) {
      console.log('Products:', data.data);
    }
  });
