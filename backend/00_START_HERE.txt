📊 DATABASE SCHEMA
═════════════════════════════════════════════════════════════════════════════════

USERS TABLE
  id (UUID PK) | name | email (UNIQUE) | password (hashed) | role (ENUM) | timestamps

PRODUCTS TABLE
  id (UUID PK) | merchant_id (FK) | name | description | price | image | timestamps

CART TABLE
  id (UUID PK) | user_id (FK) | product_id (FK) | quantity (>0) | timestamps

ORDERS TABLE
  id (UUID PK) | user_id (FK) | product_id (FK) | quantity | status (ENUM) | timestamps

Features:
  ✓ UUID primary keys
  ✓ Foreign key constraints
  ✓ Auto-increment timestamps
  ✓ Indexed for performance
  ✓ Row-level security (RLS)
  ✓ Cascading deletes
